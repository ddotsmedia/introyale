# CONTENT-GUIDE

Status: skeleton (M1). Filled as milestones land.

## Editing page content (blocks)

Everything on the public pages is edited in /admin. Nothing in the code carries page text, images, phone numbers or emails.

- **Home**: Globals, Home page. Add, drag to reorder, edit or hide sections. Each block has a "Hide" checkbox.
- **Studio, Process, Clients, Contact, Start, Work, Thank you, legal pages**: Pages collection. Same blocks.
- **Sector and service pages**: the Sections field on each Sector or Service.
- **Blocks**: Hero, Intro and stats, Featured work, Sector tiles, Services list, Process steps, Client logos, Call-to-action band, Image and text, Text section, Contact details, Enquiry form.
- **Stats** read verified facts. Change a number in Facts Register (set the value and the display text).
- **Contact details** (phone, WhatsApp, email, address) are facts too, so one edit updates the header, footer, contact page and structured data.
- **Header**: logo, navigation and the button label and link are in Site settings and Navigation. Footer columns and the copyright line are in Footer.
- **Form consent label** is in Consultation settings. The closing call-to-action at the end of case studies is in Site settings.
- **Projects**: name, location and year are empty because the live site never published them. Add them when confirmed; empty fields stay hidden.
- Changes appear on the site as soon as you save or publish. No rebuild is needed.
